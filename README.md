# MT1-LABEXAM — Shopping Cart Management Web Application

A Full Stack Development lab project built according to the supplied MT1 examination guidelines.

## Requirements

- Node.js (ES Modules support)
- npm
- Postman (for REST API testing)

## Project structure

```text
MT1-LABEXAM/
├── package.json
├── package-lock.json          # generated by npm install
├── httpServer.js              # Part A: built-in HTTP + FS modules
├── expressApp.js              # Part B: Express CRUD REST API
├── public/
│   └── index.html             # served through FS at GET /home
└── screenshots/
    └── README.md              # save your own examination screenshots here
```

## Setup

Open a terminal in this project directory:

```bash
npm install
```

## Part A — Node.js HTTP server (port 3000)

```bash
npm run start:http
```

Open these URLs:

| Method | URL | Expected result |
|---|---|---|
| GET | http://localhost:3000/ | Welcome HTML |
| GET | http://localhost:3000/cart | Cart items as JSON |
| GET | http://localhost:3000/about | Application information |
| GET | http://localhost:3000/home | `public/index.html`, read using `fs.readFile` |
| POST | http://localhost:3000/add-to-cart | Adds a product to the in-memory array |

### POST /add-to-cart body

Set `Content-Type: application/json` and send:

```json
{
  "id": 4,
  "productName": "Bluetooth Headphones",
  "price": 1499,
  "quantity": 1
}
```

## Part B — Express REST API (port 4000)

Open a **second terminal** in the same project directory:

```bash
npm run start:express
```

Test these endpoints in Postman:

| Method | URL | Purpose |
|---|---|---|
| GET | http://localhost:4000/cart | Retrieve all products |
| GET | http://localhost:4000/cart/1 | Retrieve product with ID 1 |
| POST | http://localhost:4000/cart | Add a product |
| PUT | http://localhost:4000/cart/1 | Update product 1 |
| DELETE | http://localhost:4000/cart/1 | Delete product 1 |

All POST and PUT requests use **Body → raw → JSON**.

### POST /cart example

```json
{
  "id": 4,
  "productName": "Bluetooth Headphones",
  "price": 1499,
  "quantity": 1,
  "category": "Electronics"
}
```

Successful creation returns HTTP **201 Created**. The response includes `totalPrice` (`price × quantity`).

### PUT /cart/1 example

```json
{
  "productName": "Wireless Mouse",
  "price": 899,
  "quantity": 3,
  "category": "Electronics"
}
```

PUT updates the supplied fields; omitted fields retain their existing values.

## Validation and error handling

- Invalid JSON or invalid/missing required fields: HTTP 400.
- Product not found: HTTP 404.
- Duplicate product ID: HTTP 409.
- Unsupported HTTP method on a known Part A route: HTTP 405.
- Unsupported content type for Part A POST: HTTP 415.
- Unknown routes: HTTP 404.
- File read failure for `/home`: HTTP 500.
- Both applications use separate in-memory arrays and run independently.

## Important notes

- No database is used, as required by the question paper.
- Data resets when the relevant server process restarts.
- Part A and Part B are independent applications on ports 3000 and 4000.
- Part A does not use Express.js.
